# Запуск существующего рендерера

Основная ветка экспериментов — `roofcheck/synth.py`. Скрипт `tools/render_existing.py` запускает её на одном снимке без предварительной загрузки MoGe и не удаляет результаты предыдущих запусков.

```bash
python tools/render_existing.py \
  --image /path/to/reference.jpg \
  --reference data/objects/demo_roof_01/vantages/v1/reference.json \
  --output out/example \
  --state partially_cleared --seed 42 --scale 0.5
```

Фото должно быть очищенным от снега и **уже совмещённым с эталоном**. Одинаковый размер файла не гарантирует совпадения перспективы: для другой точки съёмки сначала нужна регистрация и перенос полигонов. В JSON нужны одна целевая кровля, четырёхугольник ската и, по возможности, контуры надстроек. Другие крыши этим скриптом не размечаются.

Состояния: `not_cleared`, `partially_cleared`, `cleared`, `thaw`. При необходимости `--texture-dir` задаёт корень локальной библиотеки материалов в структуре `ambientcg/Snow*` и `polyhaven/snow_*`; без параметра используется процедурная фактура, а пустой или нечитаемый каталог вызывает ошибку. Права на материалы нужно проверять отдельно. Данные, фотографии и веса не включены в репозиторий.

По умолчанию действует исходная обработка всей сцены (`--context scene`). Для ограничения изменений проверяемым скатом доступны `--context local --feather-px 4`: вне ROI и на размеченных препятствиях сохраняется исходный кадр, пиксели смешанного края игнорируются. При этом снег на свесе за пределами ROI исчезает, а остальная сцена не становится зимней. Если на кровле действительно нет ограждений, `--fence-mode none` отключает их автоматическую имитацию. `--structure-mode manual` использует только размеченные контуры надстроек: незамеченные трубы в этом режиме не обнаруживаются. Оба параметра по умолчанию сохраняют прежнее автоматическое поведение.

Для сравнения с материалом без изменения формы снега используйте `--texture-policy isolated` в обоих запусках; во втором добавьте `--texture-dir`. Материал получает отдельный seed и меняет только яркость снега. В метаданных записываются контрольные суммы массивов геометрии и текстур. Подробное парное сравнение и его ограничения — в [batch-existing.md](batch-existing.md).

Результат содержит изображение, ROI, диагностическую маску 0/1/255 и метаданные с хэшами. За пределами ROI, на льду, ограждениях и надстройках маска помечается 255. Существующий рендерер может изменять окружение и использует приближённые параметры; маска не является проверенной разметкой реального фото.

**Этот запуск использует `scene=None`, то есть planar fallback.** Если фактическая геометрия крыши неизвестна, рендерер использует случайный, но фиксированный для объекта prior. Генерируемая глубина в мм задаёт внешний вид симуляции и не является измерением физической толщины снега. Полный 3D-путь и обучение оцениваются отдельно.

Новый конвейер `roofcheck/roof` сохранён как эксперимент с явными масками и ограничением области генерации. Исследование и сравнение: [realism-investigation.md](realism-investigation.md).
