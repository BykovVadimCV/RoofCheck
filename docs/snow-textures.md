# Текстуры снега в RoofCheck

Этот раздел описывает экспериментальный `roofcheck/roof`, а не основной `roofcheck/synth.py`. Для существующего рендерера отдельный режим фиксированной геометрии и инструкция парного сравнения находятся в [batch-existing.md](batch-existing.md).

В `render_mode=volume` можно добавить изображение поверхности снега как деталь материала. Снежная область, объём, перекрытия и alpha подбираются до подключения текстуры: при одном seed и одинаковых остальных настройках бинарная маска и alpha совпадают с запуском без текстуры.

Пример фрагмента `sample.json`:

```json
{
  "generation": {
    "scenario": "partial_cover",
    "render_mode": "volume",
    "texture_path": "data/textures/customer_archive/archive_25_snow_patch.png",
    "texture_tile_px": 64,
    "real_texture_mix": 0.8,
    "texture_strength": 0.06
  }
}
```

Путь считается относительно `sample.json`. Параметр `texture_path` необязателен; без него используется процедурная текстура. `real_texture_mix` — доля внешней текстуры в деталях материала (0..1); `texture_strength` управляет общей интенсивностью. `texture_tile_px` задаёт размер повторяемого фрагмента в условных координатах ската (16..1024), не метрах. Для `render_mode=flat` внешний материал не поддерживается.

При обработке удаляется низкочастотная составляющая цвета: освещение исходной сцены и альбедо текстуры не накладываются целиком на новое фото. Материал случайно поворачивается, сдвигается и проектируется с mip-фильтрацией. Повторяющиеся рисунки и несоответствие масштаба могут оставаться. `metadata.json` содержит путь, SHA-256, способ обработки и поля происхождения, если рядом с картинкой есть одноимённый JSON.

## Подключённые файлы

- `data/textures/customer_archive/archive_25_snow_patch.png`: участок 40×40 пикселей с реального зимнего кадра из архива заказчика. Соседний JSON хранит координаты, хэш изображения и группу `archive_winter_other_building`. Маска исходного снега выделена ассистентом, требуется проверка. Участок мал и может повторяться при нанесении.
- `data/textures/ambientcg/Snow002/Snow002_color_2k.jpg`: материал [ambientCG Snow002](https://ambientcg.com/a/Snow002), [CC0](https://docs.ambientcg.com/license/), найден в ранее загруженной локальной библиотеке. Способ создания именно этого материала в рамках проверки не установлен; он не выдаётся за подтверждённый фотоскан.

Для текстуры с JSON-происхождением `split=val` или `split=test` генерация запрещена. Текстура из реальной фотографии создаёт зависимость от её исходного объекта: нельзя помещать исходную фотографию и другие фото этого объекта в независимую контрольную выборку. Группировку и происхождение всех исходных активов требуется проверить при подготовке полноценного датасета; этот модуль не заменяет общей проверки разбиения.

Файлы `data/textures/` исключены из Git. При переносе проекта их необходимо скопировать или скачать отдельно. Для изображений с неизвестными правами и происхождением ответственность за проверку лежит на владельце набора.

Примеры до/после на одном источнике, с одинаковыми alpha и масками: `out/snow_texture_real_photo/comparison.jpg` и `out/snow_texture_comparison/comparison.jpg`. Сравнение — визуальная проверка, а не доказательство прироста качества модели.
