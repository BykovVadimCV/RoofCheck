# Разметка реальных снимков: съёмка с высотных зданий

## Что размечается

**Один раз на точку съёмки (эталон):**
- `roof` — проверяемая кровля, как её обводит заказчик. Достаточно грубо.
- `slope` — 4 угла ската по порядку: карниз-лево, карниз-право, конёк-право, конёк-лево. Боковые стороны поправятся по фальцам автоматически.
- `exclude` — кровля, с которой ведётся съёмка, и всё, что не должно влиять на привязку.
- `other_roof` — другие кровли в кадре, грубо. Нужны только для синтетики.
- `structure` — трубы, вентблоки, тарелки, слуховые окна на проверяемом скате, по одному контуру на предмет. Нужны синтетике: на скате под ними снега нет, сверху ложится шапка.

**На каждом зимнем снимке, внутри `roof`** (маски, предразметка SAM 2: клик → маска → правка):

| Метка | Что |
|---|---|
| `snow` | Снег на скате, в том числе тонкий слой, через который видно покрытие |
| `metal_clean` | Чистое сухое покрытие |
| `metal_wet` | Мокрое покрытие и блики. **Не снег**, даже если светлое |
| `ice` | Наледь на покрытии |
| `structure` | Трубы, вентшахты, слуховые окна, антенны, тарелки |
| `fence` | Ограждение, снегозадержатели |
| `overhang` | Снежный свес за линией карниза |
| `ignore` | Метка времени, значок GPS, то, что нельзя разглядеть |

**На каждом снимке, атрибуты:**
- Решение эксперта: убрано / не убрано / нельзя оценить.
- Если известна толщина (мерная рейка, акт), её значение в см.

## Правила

1. **Спорный пиксель** (снег или блик, на границе) помечается `ignore`, а не угадывается.
2. **Тонкий слой, через который видны фальцы, — это `snow`.** Порог толщины для решения задаёт заказчик. Он применяется к доле, а не к разметке.
3. **Одну и ту же точку съёмки размечает один человек.** 10% снимков размечаются дважды разными людьми — так меряется согласованность разметки. Модель не может быть точнее, чем совпадают между собой два разметчика.

## Выборки

- Делятся **по объектам** (`python3 -m roofcheck.split`). Все снимки одного объекта — со всех точек и за все даты — попадают в одну выборку.
- **Тестовая выборка фиксируется** после первых устойчивых снегопадов (`data/frozen_test.json`) и больше не меняется. Новые объекты идут только в обучение и проверку.
- В тест попадает только реальная съёмка. Синтетика — никогда.
